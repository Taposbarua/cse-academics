# Programming Practice 🧠

A collection of small C++ exercises used to strengthen programming fundamentals and problem-solving skills.

## 📚 Exercises

- `even_odd.cpp` — Determines whether a number is even or odd.
- `factorial.cpp` — Calculates the factorial of an integer.

## 💻 Language

**C++**

## 🎯 Focus

These exercises provide practice with:

- Conditional statements
- Loops
- Arithmetic operations
- Variables and data types
- Basic problem solving

> Small exercises build strong fundamentals.
